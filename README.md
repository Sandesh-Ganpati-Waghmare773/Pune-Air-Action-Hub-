# Pune Air Action Hub — WordPress Development

## 📌 Project

**Pune Air Action Hub Website**

This repository documents my contribution to the development and design of the Pune Air Action Hub website using WordPress.

The project gave me practical experience in building and managing a real-world website for an environmental organisation.

---

## 👨‍💻 My Role

I worked on the **design, development, customization, and implementation of the website using WordPress**.

My main responsibility was to convert the required website structure and content into a professional, responsive, and user-friendly website.

---

## 🛠️ What I Worked On

### 1. WordPress Website Development

* Set up and worked with the WordPress environment.
* Created and organised website pages.
* Structured the website according to the required content and navigation.
* Managed website content and page layouts.
* Configured the overall website structure.

### 2. UI/UX Design

* Designed the visual layout of different website sections.
* Created clean and professional page structures.
* Worked on spacing, alignment, typography, buttons, cards, sections, and containers.
* Maintained a consistent design across different pages.
* Focused on making the website easy to navigate.

### 3. Elementor Development

* Used **Elementor** to build and customise page layouts.
* Created sections and containers.
* Designed responsive layouts.
* Configured columns, inner containers, buttons, cards, headings, images and other Elementor elements.
* Adjusted layouts for different screen sizes.
* Customised Elementor components according to the required design.

### 4. Astra Theme Customisation

* Worked with the **Astra WordPress theme**.
* Customised the website header and footer.
* Worked on navigation and page-level layouts.
* Adjusted theme settings to match the required visual design.
* Integrated the Astra theme with Elementor layouts.

### 5. Responsive Design

I worked on making the website responsive across:

* Desktop
* Laptop
* Tablet
* Mobile

This included adjusting:

* Container widths
* Padding and margins
* Font sizes
* Button sizes
* Column layouts
* Image sizes
* Spacing between sections
