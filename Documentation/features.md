# Pune Air Action Hub – Implemented Features

This document describes the main features and website components that I implemented or customized during the development of the Pune Air Action Hub website.

## 1. Multi-Page Website Structure

I created and organised the website into multiple pages according to the required website structure.

The navigation was organised so users can easily move between different sections.

## 2. Header and Navigation

I worked on:

* Website header
* Logo placement
* Navigation menu
* Navigation spacing
* Menu alignment
* Header styling
* Responsive navigation

The navigation was tested to ensure that users can access the required pages easily.

## 3. Hero Section

I designed and customised the main hero section with:

* Main heading

* Background elements
* Image/content alignment

The hero section was designed to provide a clear introduction and guide users towards important sections.
