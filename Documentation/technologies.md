# Technologies Used

## WordPress

**WordPress** was used as the main Content Management System (CMS) for developing and managing the website.

I used WordPress for:

* Creating pages
* Managing website content
* Managing navigation
* Configuring website settings
* Managing forms and website components
* Organising the overall website structure

---

## Elementor

**Elementor** was used as the primary page builder.

I used Elementor to create and customise:

* Sections
* Containers
* Inner containers
* Columns
* Headings
* Text blocks
* Images
* Buttons
* Cards
* Icons
* Call-to-action sections
* Responsive layouts

Elementor allowed me to visually build and customise the website while controlling the layout and design of individual components.

---

## Astra Theme

The **Astra WordPress theme** was used as the base theme.

I customised the theme to match the required website design.

My work included:

* Header customization
* Footer customization
* Navigation
* Typography
* Layout settings
* Theme styling
* Integration with Elementor

---

## HTML

**HTML** was used as the fundamental structure of web content.

I worked with HTML concepts when customising website elements and understanding the structure of the generated web pages.

---

## CSS

**CSS** was used to customise the visual appearance of the website.

I used CSS for:

* Spacing
* Margins
* Padding
* Typography
* Colours
* Buttons
* Cards
* Containers
* Alignment
* Responsive adjustments
* Other visual customizations

Custom CSS was used whenever the required design could not be achieved using the default Elementor settings.

---

## JavaScript

**JavaScript** was used where required for website interactions and custom functionality.

I also developed an understanding of how JavaScript can be integrated with WordPress websites for client-side interactions.

---

## Hostinger

**Hostinger** was used for website hosting and deployment.

I worked with the hosting environment to:

* Deploy the WordPress website.
* Manage the website hosting environment.
* Connect the website with its domain.
* Make the website publicly accessible.

---

## Git & GitHub

**Git and GitHub** are being used to document and showcase the project.

Git is used for version control, while GitHub is used to maintain the project repository and present the project as part of my development portfolio.

The repository contains:

* Project documentation
* Screenshots
* Custom code
* Project information

Sensitive information such as passwords, API keys and hosting credentials is not included in the repository.
