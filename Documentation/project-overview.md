# Pune Air Action Hub – Project Overview

## Project Title

**Pune Air Action Hub – WordPress Website Development**

## Project Type

Real-World Web Development Project

## My Role

I worked on the design, development, customization, and deployment of the Pune Air Action Hub website using WordPress.

My role mainly involved converting the required website structure and design requirements into a functional, responsive, and professional website.

## Project Work

I worked on the website from the development stage to the live deployment stage.

My work included:

* Understanding the website requirements and structure.
* Planning the layout of different pages and sections.
* Creating and arranging pages in WordPress.
* Building website layouts using Elementor.
* Customizing the Astra theme.
* Designing reusable sections and containers.
* Creating responsive layouts for different screen sizes.
* Customizing buttons, cards, headings, images, navigation and other UI elements.
* Applying custom CSS wherever required.
* Configuring website forms and user-input sections.
* Creating and managing website navigation.
* Connecting buttons and sections to appropriate pages.
* Testing the website and fixing layout issues.
* Optimizing the design for desktop, tablet and mobile screens.
* Deploying the website on Hostinger.

## Development Process

The project was developed through the following process:

### 1. Requirement Understanding

I first understood the required pages, sections, content structure, navigation and design expectations.

### 2. Website Structure

I organised the website into appropriate pages and created the navigation structure.

### 3. UI Development

I created the page layouts using Elementor and worked on containers, sections, cards, buttons, images, headings and other interface components.

### 4. Theme Customization

I used the Astra theme as the base and customized its appearance and layout to match the required design.

### 5. Responsive Development

I adjusted the layouts for desktop, tablet and mobile devices.

### 6. Customization

Where the default Elementor options were not sufficient, I used custom CSS and other required customizations.

### 7. Testing

I tested the pages, navigation, forms, buttons and responsive layouts and fixed issues identified during development.

### 8. Deployment

After completing development and testing, the website was deployed using Hostinger and made available online.
